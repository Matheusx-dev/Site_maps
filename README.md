# Clínica Movimento — projeto de portfólio

Página estática demonstrativa para apresentar uma proposta de site para uma clínica de fisioterapia.

> A marca, os depoimentos, o endereço e os contatos são fictícios/demonstrativos. O formulário não envia dados. Substitua essas informações e confirme os direitos de uso dos recursos antes de adaptar o projeto para um cliente real.

## Tecnologias

- HTML5
- CSS responsivo
- JavaScript sem dependências
- Ilustrações SVG originais do conceito

## Visualização local

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub (público para portfólio aberto ou privado para rascunho).
2. Envie `index.html`, este README e a pasta `assets` com a logo e as ilustrações referenciadas pela página.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço indicado na página de configurações do Pages.

As imagens antigas que não são referenciadas pelo HTML não são necessárias para a publicação. Remova-as antes do envio, caso não tenha autorização para redistribuí-las.
